은혜의 찬양 (Grace Song) - PWA 체험판

구성:
- index.html: 앱 화면과 추천 기능
- icon-192.png / icon-512.png: 두 번째 브랜드 이미지 기반 앱 아이콘
- manifest.webmanifest: 홈 화면 설치 정보
- sw.js: 기본 오프라인 캐시

사용:
1. 폴더 전체를 HTTPS를 지원하는 정적 웹 호스팅에 올립니다.
2. 스마트폰 Chrome에서 배포된 주소를 엽니다.
3. 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.

주의:
현재 추천은 파일에 포함된 예시 찬양 데이터의 키워드 매칭 방식입니다.
실제 생성형 AI, 최신 찬양 데이터베이스, 교단/검증기관의 공식 자료 자동 조회,
저작권이 허용된 음원 재생은 아직 연동되지 않았습니다.
